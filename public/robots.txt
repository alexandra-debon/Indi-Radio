# ============================================================
# Cohérence des URL (anti-doublons)
# ============================================================
# Une seule forme d'URL est canonique : apex https, sans slash final,
# sans paramètre — sauf `?hl=en` (version anglaise) et `?page=N` (pagination).
# `?hl=en` est la version anglaise déclarée en hreflang et listée dans
# /sitemap-en.xml : ces URL DOIVENT rester crawlables, sinon le hreflang
# est cassé. Ne pas supprimer les lignes `Allow: /*?hl=`.
# Les paramètres de tracking créent des doublons : on les bloque.
Allow: /*?hl=
Allow: /*?page=
Disallow: /*?*utm_
Disallow: /*?*fbclid=
Disallow: /*?*gclid=
Disallow: /*?*mc_cid=
Disallow: /*?*ref=
